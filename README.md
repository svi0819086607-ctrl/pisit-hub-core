# pisit_hub — แกนกลาง (ฉบับเผยแพร่)

แกนกลางของ **pisit_hub** ระบบงานภายในแบบปลั๊กอินของบริษัทครอบครัวผม เริ่มใช้งานจริงตั้งแต่เดือนมิถุนายน 2569 (11 โปรแกรมสำหรับ 7 แผนก ตอนนี้ใช้จริงแล้ว 3 แผนก คือบัญชี บุคคล และฝ่ายขาย ส่วนผลิต คลัง QC และจัดซื้ออยู่ในช่วงย้ายมาใช้) พนักงานเปิดใช้ผ่านเบราว์เซอร์ เซิร์ฟเวอร์เขียนด้วย Python (Flask + waitress) เก็บข้อมูลใน SQLite

ผู้จัดทำ: พิสิษฐ์ เกจณะเวชช์

## มีอะไรใน repo นี้

| ไฟล์ | บรรทัด | หน้าที่ | เทียบกับระบบจริง |
|---|---|---|---|
| `core/registry.py` | 189 | ระบบปลั๊กอิน: `discover()` สแกนโฟลเดอร์ `programs/` แล้วลงทะเบียนโปรแกรมเอง โฟลเดอร์ไหนโหลดไม่ขึ้นจะถูกข้าม | ตรงทุกไบต์ |
| `app.py` | 488 | ตัวเปิดเซิร์ฟเวอร์: ด่านตรวจทุกคำขอ (หมดเวลา session · วงเครือข่าย · อุปกรณ์ · สิทธิ์เห็นโปรแกรม) ล็อกอินและ OTP บีบอัดคำตอบ บันทึกเหตุการณ์ | ตัดบางส่วน |
| `core/users.py` | 480 | ผู้ใช้ สิทธิ์เห็นโปรแกรมรายคน รหัส OTP ทางอีเมล กันเดารหัสผ่าน จำอุปกรณ์ที่ผ่าน OTP แล้ว | ตัดบางส่วน |
| `core/auth.py` | 59 | ตรวจรหัสผ่าน และตัวกำกับ `login_required` / `admin_required` | ตรงทุกไบต์ |
| `core/access.py` | 224 | บันทึกการใช้งาน คลังอุปกรณ์ จำกัดวงเครือข่ายที่เข้าได้ | ตรงทุกไบต์ |
| `core/eventlog.py` | 91 | บันทึกเหตุการณ์ของทั้งระบบ | ตรงทุกไบต์ |
| `core/backup.py` | 362 | สำรองและกู้คืนข้อมูล ตั้งเวลาสำรองอัตโนมัติ | ตรงทุกไบต์ |
| `core/db.py` | 263 | โครงสร้างตาราง SQLite และค่าตั้งต้นของระบบ | ตัดบางส่วน |
| `config.py` | 65 | ค่าตั้งกลาง | ค่าสมมุติ 2 จุด |

จุดที่แนะนำให้เริ่มอ่าน

- `core/registry.py` ฟังก์ชัน `discover()` — หลักการ "1 โฟลเดอร์ = 1 โปรแกรม" เพิ่มโปรแกรมใหม่โดยไม่ต้องแก้แกนกลาง
- `app.py` ฟังก์ชัน `_gate()` — ด่านตรวจที่ทุกคำขอต้องผ่าน
- `app.py` เส้นทาง `/login` และ `/login-otp` กับ `core/users.py` ส่วน OTP — ล็อกอินสองชั้น

## สิ่งที่ไม่อยู่ใน repo นี้

- โปรแกรม 11 ตัวในโฟลเดอร์ `programs/` (งานของแต่ละแผนก)
- แชท คลังไฟล์ และข้อมูลกลาง (Data API) ที่โปรแกรมใช้ฝากและแลกข้อมูลกัน
- หน้าหลังบ้านของผู้ดูแล ระบบขอลาผ่าน LINE ส่วนงานรายแผนก และ Cloudflare Tunnel
- `templates/` `static/` ชุดทดสอบ และข้อมูลจริงทั้งหมด

โค้ดชุดนี้จึง**รันตามลำพังไม่ได้** มีไว้ให้อ่าน

## สิ่งที่ปรับก่อนเผยแพร่

- ตัดส่วนในหัวข้อข้างบนออกจาก `app.py` `core/db.py` และ `core/users.py` ทุกจุดที่ตัดมีคำว่า `[ตัดออก]` กำกับไว้ในไฟล์
- ชื่อองค์กร อีเมลผู้ส่ง OTP และรหัสผู้ดูแลเริ่มต้น เปลี่ยนเป็นค่าสมมุติ
- ไม่มีการเขียนการทำงานใหม่เพิ่ม ส่วนที่เหลือคือโค้ดเดียวกับที่ระบบจริงใช้

## ใครเขียน

โค้ดทั้งหมดเขียนด้วย Claude Code (AI) รวมถึงการคัดและตัดฉบับเผยแพร่นี้ ส่วนที่ผมทำเองคือ รับโจทย์จากผู้ใช้แต่ละแผนก ออกแบบโครงสร้างข้อมูลและสิทธิ์ ตรวจผลงานของ AI ทดสอบกับผู้ใช้ก่อนเปิดใช้งาน และติดตั้งดูแลระบบ
